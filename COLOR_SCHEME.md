# Dragon Spirit Martial Arts Color Scheme

## Official Color Palette (3 Base Colors)

### 1. Black/Dark Gray
- **Primary**: `gray-900` - Navigation, headers, primary sections
- **Secondary**: `gray-800` - Gradients, secondary headers
- **Light**: `gray-100`, `gray-50` - Backgrounds

### 2. Red
- **Primary**: `red-600` - CTAs, important buttons, accents
- **Hover**: `red-700` - Button hover states
- **Light**: `red-100` - Backgrounds for status indicators

### 3. Gold/Amber
- **Primary**: `amber-500`, `amber-600` - Achievements, featured items, admin sections
- **Light**: `amber-400` - Secondary text, category labels
- **Background**: `amber-50`, `amber-100` - Highlight backgrounds

## Usage Guidelines

- **Headers/Navigation**: Gray-900 background, white text
- **Hero Sections**: Gray-900 to Gray-800 gradient
- **Primary CTAs**: Red-600 (red-700 on hover)
- **Secondary CTAs**: Gray-900
- **Featured/Special Items**: Amber-500 borders or badges
- **Success States**: Red-600 (represents achievement in martial arts)
- **Admin Elements**: Amber-500/600
- **Card Headers**: Gray-900 with red-600 top border
- **Achievement Badges**: Amber-500 gradient
